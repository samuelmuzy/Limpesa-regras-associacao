# 📊 Projeto: Padronização de Dados de Vendas

Este projeto tem como objetivo a **limpeza, padronização e organização** de uma base de dados de vendas, com foco na padronização de nomes de **estados** e **cidades** e **valores** e também o plot de graficos para demostração.

## 🎯 Objetivo

- Corrigir inconsistências nos nomes de cidades e estados
- Padronizar dados com siglas de estados (UF)
- Preparar a base para análise e visualizações

## 🧪 Tecnologias Utilizadas

- Python 3
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## 📁 Estrutura

📦 projeto-padronizacao-vendas
  ├── analise.ipynb # Notebook com o processo completo
  ├── novo_arquivo.csv # Base de dados original
  ├── dados_limpos.csv # Resultado final após limpeza


## 🔍 Etapas Realizadas

- Carregamento da base com `pandas`
- Mapeamento de cidades → siglas dos estados (UF)
- Aplicação de função personalizada para padronização
- Contagem comparativa antes/depois da transformação
- Exportação da base padronizada
